**Constructor:**
```kotlin
internal class CallbackCoordinator(
    private val onAdLoaded: (AuctionResult, AuctionInfo) -> Unit,
    private val onAdLoadFailed: (AuctionInfo?, BidonError) -> Unit,
) {
    private val loadedCallbackFired = AtomicBoolean(false)
    private val failedCallbackFired = AtomicBoolean(false)
    private var cacheWasEmptyAtStart = true // Set before auction starts
```

**Methods:**

1. **setCacheEmptyAtStart(isEmpty: Boolean):**
   - Called before auction starts to record cache state
   - Used to determine if failure callback should fire

2. **notifySuccess(result: AuctionResult, auctionInfo: AuctionInfo):**
   ```kotlin
   // Returns true only on FIRST call (atomic compare-and-set)
   if (loadedCallbackFired.compareAndSet(false, true)) {
       logInfo(TAG, "Firing onAdLoaded callback")
       onAdLoaded(result, auctionInfo)
   } else {
       logInfo(TAG, "onAdLoaded already fired, skipping")
   }
   ```

3. **notifyFailure(auctionInfo: AuctionInfo?, error: BidonError):**
   ```kotlin
   // Only fires if:
   // 1. Success callback hasn't fired
   // 2. Cache was empty at start (otherwise there's still cached value)
   // 3. Failure callback hasn't fired yet
   if (!loadedCallbackFired.get() &&
       cacheWasEmptyAtStart &&
       failedCallbackFired.compareAndSet(false, true)) {
       logInfo(TAG, "Firing onAdLoadFailed callback: cache was empty and both branches failed")
       onAdLoadFailed(auctionInfo, error)
   } else {
       logInfo(TAG, "Skipping onAdLoadFailed: loadedFired=${loadedCallbackFired.get()}, cacheEmpty=$cacheWasEmptyAtStart")
   }
   ```

4. **reset():**
   - Reset both AtomicBoolean flags to false
   - Reset cacheWasEmptyAtStart to true
   - Used when starting new auction

5. **hasSuccessCallbackFired(): Boolean:**
   - Return `loadedCallbackFired.get()`
   - For external state checks

**KDoc documentation:**
- Document the exactly-once guarantee
- Document when failure callback fires (cache empty AND both fail)
- Document thread-safety (AtomicBoolean is lock-free)

**Implementation using supervisorScope:**
```kotlin
// Record current auction for cancellation support
currentAuctionId = auctionId

// Record cache state BEFORE auction
callbackCoordinator.setCacheEmptyAtStart(ReadyToShowCache.isEmpty())

currentAuctionJob = coroutineScope {
    // RTB branch (independent failure domain)
    val rtbDeferred = async {
        if (!rtbPayloadsAvailable) {
            logInfo(TAG, "Skipping RTB branch: no cached payloads")
            return@async null
        }
        supervisorScope {
            rtbProcessor.loadBestPayload(...)
        }
    }

    // CPM branch (independent failure domain)
    val cpmDeferred = async {
        if (cpmAdUnits.isEmpty()) {
            logInfo(TAG, "Skipping CPM branch: no adUnits")
            return@async null
        }
        supervisorScope {
            cpmProcessor.loadWaterfall(...)
        }
    }

    // Wait for both to complete
    val rtbResult = rtbDeferred.await()
    val cpmResult = cpmDeferred.await()

    // Check if ANY success occurred
    val rtbSuccess = rtbResult?.isSuccess == true
    val cpmSuccess = cpmResult?.firstSuccess != null

    if (rtbSuccess || cpmSuccess) {
        // Get first successful result for callback
        val firstSuccess = rtbResult?.getOrNull() ?: cpmResult?.firstSuccess
        firstSuccess?.let {
            callbackCoordinator.notifySuccess(it, auctionInfo)
        }
    } else {
        // Both failed - notify failure (coordinator checks cache state)
        callbackCoordinator.notifyFailure(auctionInfo, BidonError.NoFill("auction"))
    }
}
```

**Cancellation support:**
```kotlin
fun cancelIfSameAuction(auctionId: String) {
    if (currentAuctionId == auctionId) {
        logInfo(TAG, "Cancelling auction $auctionId (ad shown)")
        currentAuctionJob?.cancel()
        currentAuctionJob = null
        currentAuctionId = null
    } else {
        logInfo(TAG, "Not cancelling: shown ad from different auction")
    }
}
```

**Critical behaviors:**
- Both branches run to completion (supervisorScope isolates failures)
- RTB failure doesn't cancel CPM and vice versa
- Callback fires when cache transitions empty -> non-empty (first success)
- Cancellation is conditional on matching auctionId
