**Implementation steps:**

1. **Sort adUnits by weighted score:**
   - Call `weightModel.sortByWeightedScore(adUnits)`
   - This orders by eCPM × weight factor (higher fill rate networks prioritized)

2. **Sequential loading loop:**
   ```kotlin
   var successCount = 0
   var failureCount = 0
   var firstSuccess: AuctionResult? = null

   for (adUnit in sortedAdUnits) {
       ensureActive() // Check cancellation before each load

       val result = loadSingleAdUnit(adUnit, ...)

       if (result.isSuccess) {
           weightModel.recordFill(adUnit.demandId)
           successCount++
           if (firstSuccess == null) firstSuccess = result.getOrNull()
       } else {
           weightModel.recordNoFill(adUnit.demandId)
           failureCount++
           logInfo(TAG, "CPM load failed: ${adUnit.demandId}, error=${result.exceptionOrNull()}")
           // Continue to next adUnit (don't stop waterfall)
       }
   }
   ```

3. **Single adUnit loading (private helper):**
   - Create AdSource for the adapter
   - Apply params (same as RtbProcessor)
   - Load and wait for AdEvent
   - On success: Create CacheEntry, store in ReadyToShowCache
   - On failure: Return failure result (don't throw)
   - Always destroy AdSource in finally block if not ready

**Critical behavior:**
- Continue loading ALL adUnits even after first success (fills the cache)
- Record fill/no-fill for EVERY attempt (builds weight model)
- Don't stop early - we want to fill ReadyToShowCache with multiple ads

Implement the single adUnit loading helper:

**Function signature:**
```kotlin
private suspend fun loadSingleAdUnit(
    adUnit: AdUnit,
    adTypeParam: AdTypeParam,
    demandAd: DemandAd,
    auctionId: String,
    auctionConfigurationId: Long,
    auctionConfigurationUid: String,
    externalWinNotificationsEnabled: Boolean,
    pricefloor: Double,
): Result<AuctionResult>
```

**Implementation:**

1. **Find adapter:**
   - Look up adapter by `adUnit.demandId` from adaptersSource
   - If not found: Return `Result.failure(BidonError.UnknownAdapter(adUnit.demandId))`

2. **Create AdSource:**
   - Apply regulation to adapter
   - Create appropriate AdSource for ad type
   - Apply auction params (auctionId, configId, etc.)

3. **Load with timeout:**
   ```kotlin
   var adSource: AdSource<AdAuctionParams>? = null
   return try {
       adSource = createAdSource(adapter, demandAd, adTypeParam)
           ?: return Result.failure(BidonError.UnknownAdapter(adUnit.demandId))

       applyParams(adSource, ...)

       val adParams = adSource.getAuctionParam(
           AdAuctionParamSource(
               activity = adTypeParam.activity,
               pricefloor = pricefloor,
               optBannerFormat = (adTypeParam as? AdTypeParam.Banner)?.bannerFormat,
               optContainerWidth = (adTypeParam as? AdTypeParam.Banner)?.containerWidth,
               adUnit = adUnit,
           )
       ).getOrNull() ?: return Result.failure(BidonError.NoFill(adUnit.demandId))

       val adEvent = withTimeout(adUnit.timeout) {
           adSource.adEvent
               .onSubscription { adSource.load(adParams) }
               .first { it is AdEvent.Fill || it is AdEvent.LoadFailed || it is AdEvent.Expired }
       }

       when (adEvent) {
           is AdEvent.Fill -> {
               // Store in ReadyToShowCache
               val entry = CacheEntry.create(
                   value = AuctionResult.Network(adSource, RoundStatus.Successful),
                   ecpm = adEvent.ad.price,
                   demandId = adUnit.demandId,
                   auctionId = auctionId
               )
               ReadyToShowCache.put(entry)
               Result.success(entry.value)
           }
           else -> Result.failure(BidonError.NoFill(adUnit.demandId))
       }
   } catch (e: CancellationException) {
       throw e // NEVER catch CancellationException
   } catch (e: Exception) {
       Result.failure(e)
   } finally {
       if (adSource?.isAdReadyToShow != true) {
           adSource?.destroy()
       }
   }
   ```

4. **Add logging:**
   - Log start: "CPM loading: demandId=${adUnit.demandId}, ecpm=${adUnit.pricefloor}, weight=${weightModel.getWeight(adUnit.demandId)}"
   - Log success: "CPM loaded: demandId=${adUnit.demandId}"
   - Log failure: "CPM failed: demandId=${adUnit.demandId}, continuing waterfall"
