  <name>Task 1: Create WeightModel singleton with atomic weight tracking</name>
  <files>bidon/src/main/java/org/bidon/sdk/ads/cache/denis/processors/WeightModel.kt</files>
  <action>
Create WeightModel as a singleton object with the following implementation:

**Storage:**
- Use `ConcurrentHashMap<String, AtomicInteger>` for thread-safe weight storage (demandId -> weight)
- Constants: `DEFAULT_WEIGHT = 10`, `MIN_WEIGHT = 1`, `MAX_WEIGHT = 20`

**Core methods:**

1. `recordFill(demandId: String)`:
   - Get or create weight for demandId (default 10)
   - Use `updateAndGet` to atomically increment: `(current + 1).coerceIn(MIN_WEIGHT, MAX_WEIGHT)`
   - Log the update

2. `recordNoFill(demandId: String)`:
   - Get or create weight for demandId (default 10)
   - Use `updateAndGet` to atomically decrement: `(current - 1).coerceIn(MIN_WEIGHT, MAX_WEIGHT)`
   - Log the update

3. `getWeight(demandId: String): Int`:
   - Return weight or DEFAULT_WEIGHT if not found

4. `sortByWeightedScore(adUnits: List<AdUnit>): List<AdUnit>`:
   - Sort by descending weighted score: `adUnit.pricefloor * (weight / 10.0)`
   - Higher score = higher priority

5. `clear()`:
   - Clear all weights (for testing)

**Implementation notes:**
- Use `java.util.concurrent.atomic.AtomicInteger` for lock-free atomic updates
- Use `getOrPut` pattern: `weights.getOrPut(demandId) { AtomicInteger(DEFAULT_WEIGHT) }`
- Mark as `internal object` for singleton pattern
- Add TAG for logging consistency
