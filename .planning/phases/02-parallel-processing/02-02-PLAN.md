  <name>Task 1: Create RtbProcessor with loadBestPayload function</name>
  <files>bidon/src/main/java/org/bidon/sdk/ads/cache/denis/processors/RtbProcessor.kt</files>
  <action>
Create RtbProcessor as an internal class with the following structure:

**Constructor dependencies:**
```kotlin
internal class RtbProcessor(
    private val adaptersSource: AdaptersSource,
    private val regulation: Regulation,
)
```

**Main function signature:**
```kotlin
suspend fun loadBestPayload(
    adTypeParam: AdTypeParam,
    demandAd: DemandAd,
    auctionId: String,
    auctionConfigurationId: Long,
    auctionConfigurationUid: String,
    externalWinNotificationsEnabled: Boolean,
    pricefloor: Double,
): Result<AuctionResult>
```

**Implementation steps:**

1. **Get best payload from cache:**
   - Call `RtbPayloadCache.getAllSortedByEcpm()` to get payloads sorted by eCPM
   - Get first (highest eCPM) payload
   - If cache is empty, return `Result.failure(BidonError.NoFill(demandId = "RTB"))`

2. **Check cancellation before load:**
   - Call `ensureActive()` before starting load (respects coroutine cancellation)

3. **Get adapter and create AdSource:**
   - Find adapter by `payload.adUnit.demandId` from adaptersSource
   - Apply regulation via `adapter.applyRegulation()`
   - Create AdSource based on ad type (similar to ExecuteAuctionUseCaseImpl pattern)
   - Set token info from payload: `adSource.setTokenInfo(payload.tokenInfo)`

4. **Load the ad:**
   - Use the same pattern as RequestAdUnitUseCaseImpl
   - Subscribe to `adSource.adEvent` flow
   - Call `adSource.load(adParams)`
   - Wait for `AdEvent.Fill`, `AdEvent.LoadFailed`, or `AdEvent.Expired`
   - Use `withTimeout(payload.adUnit.timeout)` for timeout handling

5. **Handle success:**
   - On `AdEvent.Fill`: Create CacheEntry and store in ReadyToShowCache
   - Return `Result.success(AuctionResult.Bidding(adSource, RoundStatus.Successful))`

6. **Handle failure:**
   - On failure: Remove payload from RtbPayloadCache (invalid bid)
   - Log failure: `logInfo(TAG, "RTB load failed: demandId=${demandId}, error=$error")`
   - Destroy AdSource in finally block
   - Return `Result.failure(BidonError.NoFill(demandId))`

**Critical pitfall avoidance:**
- NEVER catch CancellationException (always rethrow)
- Always call `ensureActive()` before long operations
- Destroy AdSource in finally block even on cancellation
