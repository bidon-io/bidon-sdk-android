Refactor loadBestPayload() to fix two gaps:

**Gap 1: Finally block for AdSource cleanup**
- Current: Multiple early returns call destroy() in catch blocks only
- Fix: Wrap AdSource operations in try-finally pattern
- Model after CpmProcessor pattern (lines 248-253)
- AdSource.destroy() must be called in finally block unless successfully loaded

**Gap 2: Retry logic for RTB payloads (RTB-02/RTB-03)**
- Current: Only attempts first payload from getAllSortedByEcpm()
- Fix: Loop over payloads, try each until success or exhaustion
- On failure: Remove invalid payload from cache, continue to next
- On success: Store in ReadyToShowCache, exit loop with success

Implementation pattern:
```kotlin
suspend fun loadBestPayload(...): Result<AuctionResult> = coroutineScope {
    val payloads = RtbPayloadCache.getAllSortedByEcpm()

    if (payloads.isEmpty()) {
        return@coroutineScope Result.failure(BidonError.NoFill(...))
    }

    // Try each payload until success (retry logic for RTB-03)
    for (payload in payloads) {
        ensureActive() // Check cancellation

        val adapter = findAdapter(payload.demandId) ?: continue
        val adSource = createAdSource(adapter, ...) ?: continue

        // Track for cleanup
        var loadSuccess = false
        try {
            // Load attempt
            val result = loadWithTimeout(adSource, payload)
            if (result.isSuccess) {
                loadSuccess = true
                // Store in ReadyToShowCache
                ReadyToShowCache.put(cacheEntry)
                RtbPayloadCache.remove(demandId) // Loaded successfully
                return@coroutineScope result
            } else {
                // Load failed - remove invalid payload (RTB-05)
                RtbPayloadCache.remove(demandId)
                // Continue to next payload (retry)
            }
        } catch (e: CancellationException) {
            throw e // Always rethrow
        } catch (e: Exception) {
            RtbPayloadCache.remove(demandId)
            logInfo(TAG, "RTB load failed, trying next: $demandId")
        } finally {
            // Cleanup unless successfully loaded
            if (!loadSuccess) {
                adSource.destroy()
            }
        }
    }

    // All payloads exhausted
    Result.failure(BidonError.NoFill(...))
}
```

Key changes:
1. Replace single payload handling with for loop over sorted payloads
2. Track `loadSuccess` flag for finally block decision
3. Remove ALL early returns that bypass cleanup
4. destroy() only in finally, only when !loadSuccess
5. On adapter/adSource creation failure: use continue (no destroy needed - nothing created)
6. Remaining valid payloads naturally stay in cache (not removed unless load attempted)
