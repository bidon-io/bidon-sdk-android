**cache() implementation:**
- Launch on scope to avoid blocking caller
- Call coordinationLayer.coordinateAuction() with callbacks
- Wrap callbacks in withContext(Dispatchers.Main) for thread safety
- Handle both WarmStartServed and ColdStartInProgress completion types
- Convert BidonError to Throwable for onFailure (BidonError extends Throwable, direct pass-through)

**pop() implementation:**
- Call ReadyToShowCache.popBest() to get highest eCPM ad
- If entry found, cancel ongoing auction via lifecycleManager.cancelAuction(entry.auctionId)
- Log at INFO level: "pop: served cached ad demandId=${entry.demandId}, ecpm=${entry.ecpm}"
- Return entry.value (AuctionResult) or null

**peek() implementation:**
- Call ReadyToShowCache.peekBest() (non-destructive read)
- Return AuctionResult or null

**poll() implementation:**
- Call peek() first
- If null, throw NoSuchElementException("Cache is empty")
- Return the peeked result
- NOTE: Old V1 impl waited for ad, V2 does NOT wait - returns immediately

**clear() implementation:**
- NO-OP per CONTEXT.md decision
- Log at INFO level: "clear() called - NO-OP per design (caches clear via expiration only)"

**withSettings() implementation:**
- Call ReadyToShowCache.setCapacity(settings.cacheCapacity)
- Log at INFO level: "Cache settings applied: capacity=${settings.cacheCapacity}"
