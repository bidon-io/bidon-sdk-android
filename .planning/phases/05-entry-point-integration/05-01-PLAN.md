**Constructor:**
```kotlin
internal class AdCacheDenisImpl(
    override val demandAd: DemandAd,
    private val resolver: AuctionResolver,
    private val coordinationLayer: CoordinationLayer,
    private val lifecycleManager: LifecycleManager,
    private val scope: CoroutineScope = CoroutineScope(SdkDispatchers.Main + SupervisorJob()),

```

Note: Keep resolver parameter for V1 compatibility even though V2 doesn't use it.

**Required imports:**
- kotlinx.coroutines.* (CoroutineScope, SupervisorJob, launch, Dispatchers)
- org.bidon.sdk.ads.cache.denis.orchestration.CoordinationLayer
- org.bidon.sdk.ads.cache.denis.lifecycle.LifecycleManager
- org.bidon.sdk.ads.cache.denis.stores.ReadyToShowCache
- org.bidon.sdk.utils.SdkDispatchers
- org.bidon.sdk.logs.logging.impl.logInfo

**cache() implementation:**
- Launch on scope to avoid blocking caller
- Call coordinationLayer.coordinateAuction() with callbacks
- Forward callbacks directly: `onSuccess = { result, info -> onSuccess(result, info) }`
- onFailure: BidonError extends Throwable, so direct pass-through works: `onFailure = { info, error -> onFailure(info, error) }`
- Handle both WarmStartServed and ColdStartInProgress completion types

**pop() implementation:**
- Call ReadyToShowCache.popBest() to get highest eCPM ad
- If entry found, cancel ongoing auction via lifecycleManager.cancelAuction(entry.auctionId)
- Log at INFO level: "pop: served cached ad demandId=${entry.demandId}, ecpm=${entry.ecpm}"
- Return entry.value (AuctionResult) or null

**peek() implementation:**
- Call ReadyToShowCache.peekBest() (non-destructive read)
- Return AuctionResult or null

**poll() implementation:**
- Call pop() to get and remove best ad (highest eCPM)
- If null, throw NoSuchElementException("Cache is empty")
- Return the result
- NOTE: V1 suspended waiting for results.first(), V2 returns immediately from current cache state
- This matches non-nullable AuctionResult return signature

**clear() implementation:**
- NO-OP per CONTEXT.md decision
- Log at INFO level: "clear() called - NO-OP per design (caches clear via expiration only)"

**withSettings() implementation:**
- Call ReadyToShowCache.setCapacity(settings.cacheCapacity)
- Log at INFO level: "Cache settings applied: capacity=${settings.cacheCapacity}"

}
