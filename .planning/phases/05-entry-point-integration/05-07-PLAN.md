    **InterstitialScreen.kt changes:**

    1. Add a `cacheVersionState` remember mutableStateOf with default value `1` (V1).

    2. Add a Row below the "Pricefloor" row and above the Load/Show/Destroy row. The row should contain:
       - Body1Text with text "Cache V"
       - A set of clickable text buttons for versions 1 through 5 (matching AdCacheVersion entries). Use AppTextButton for each with text "1", "2", "3", "4", "5". The selected version button should be visually distinct (e.g., use AppButton instead of AppTextButton for the selected one).
       - When a version button is tapped, update `cacheVersionState`.

    3. In the `interstitial` lazy initialization block, right after the `InterstitialAd(auctionKey = ...)` construction but before `setInterstitialListener`, add:
       ```kotlin
       addExtra("cache_size", cacheVersionState.value)
       ```
       Note: Since `interstitial` is `by lazy`, the cache version is set at first use. To allow changing version, change `interstitial` from `by lazy` to `remember` block (matching TestInterstitialScreen pattern), and re-create InterstitialAd when cacheVersionState changes.

       Actually, since changing the interstitial mid-session would be complex and the existing V1 tests use `by lazy`, take a simpler approach:
       - Keep `by lazy` for InterstitialAd creation
       - Call `interstitial.addExtra("cache_size", cacheVersionState.value)` inside the Load button's onClick handler, BEFORE calling `interstitial.loadAd(...)`. This way each loadAd call uses the currently selected cache version.
       - This works because addExtra() updates the DemandAd extras which are read by the factory on each loadAd() call (when a new AdCache is created internally).

    4. Add a log line when load is clicked: `logFlow.log("Loading with cache V${cacheVersionState.value}")`.

    **AdCacheFactoryImpl.kt changes:**

    1. Add import for `org.bidon.sdk.logs.logging.impl.logInfo`.

    2. After the `val version = AdCacheVersion.fromInt(...)` line, add:
       ```kotlin
       logInfo(TAG, "Creating AdCache: version=$version (raw=${demandAd.getExtras()["cache_size"]})")
       ```

    3. Add at the bottom of the class (before closing brace):
       ```kotlin
       companion object {
           private const val TAG = "AdCacheFactory"
       }
       ```

    This provides visibility into which cache version is being used without any functional changes.
